# keiei-company

会社ごとに仕事の進め方を聞き取り、顧客と案件の記録を育てるための Claude Code プラグインです。最初から入っている5役は建築の積算・見積向けの**初期案**です。業務に合わなければ役割、手順、保存先を相談して変更します。

## 人が導入するとき

1. 顧客情報を入れない専用の作業フォルダを決め、必要なら自社のバックアップとアクセス制御を用意します。この公開リポジトリに実顧客情報をコミットしません。
2. Claude Code で `/plugin marketplace add yujirotn/aitm-company-kit`、次に `/plugin install keiei-company@aitm-keiei-company` を実行します。
3. 専用フォルダで `/company-setup` を実行します。AI の聞き取りと構成案を確認してから、ファイルを作ります。一度で決まらない項目は未確認のまま保存して再開できます。
4. `/new-client` で顧客を登録し、`/new-case` でその顧客の案件を作ります。個人名をフォルダ名に使う必要はありません。

既存の導入先では通常作業から始めます。構成を見直すときだけ `/company-setup 再設定` を使います。導入・再設定とも、既存ファイルを黙って上書きしません。手順は [導入と運用](docs/導入と運用.md) を参照してください。

## AI がこのリポジトリを読んだとき

最初に [導入と運用](docs/導入と運用.md) を読み、作業先の `AGENTS.md`、`導入状態.md`、`会社設定.md` の有無を確認してください。未導入、未完了からの再開、導入済みの通常利用、再設定を区別します。作業先の選択と構成案の承認は人に求めます。未確認の金額・掛け率・税・丸め・権限は推測せず、その処理を止めます。公開リポジトリには匿名サンプルしかありません。

Codex 等でプラグインを使わない場合は [導入と運用](docs/導入と運用.md) に沿って `templates/` を作業先へコピーし、`templates/AGENTS.md` を読み込ませてください。`commands/` は Claude Code のコマンド用ですが、各手順は他の AI でも実行できます。実行前に作業先と差分を人と確認してください。

## 主なコマンド

| コマンド | 用途 |
|---|---|
| `/company-setup` | 初回の聞き取り、途中再開、導入状況の確認 |
| `/company-setup 再設定` | 役割や保存方法などの変更案と適用 |
| `/new-client` | 顧客を一意の ID で登録 |
| `/new-case` | 指定顧客の案件を作成 |
| `/meeting-note` | 案件ごとの議事録を追加 |
| `/drawing-revision` | 図面の原本と改訂、最新版参照を記録 |
| `/log` | 案件の経過とやりとりを追記 |

見積、図面、議事録の運用と計算方針は作業先の `会社設定.md` と対象案件の記録が優先です。外部送信や確定は人の確認後に行います。
