# keiei-company（積算・見積を5役で進め、案件に記憶を残すプラグイン）

建築会社の積算〜見積業務を、AIの役割分担で進めるための仕組みです。
**AIは前の会話を覚えていません。覚えているのは、案件フォルダに書かれたことだけ**という前提で作ってあります。

## 入れ方（Claude Code）

```
/plugin marketplace add yujirotn/aitm-company-kit
/plugin install keiei-company@aitm-keiei-company
```

入れたら、記録を置きたいフォルダで次の順に使います。

| コマンド | いつ使うか |
|---|---|
| `/company-setup` | 最初の1回。会社の前提ファイルと案件フォルダの土台を作る |
| `/new-case 山田邸` | 新しい案件を起案するとき |
| `/log` | 作業を区切るとき・止まる前。経過ログとREADMEに残す |

## 入っている役割

統括（company-lead）／積算（estimator）／見積作成（quote-writer）／チェック（reviewer）／顧客対応（customer-care）。
依頼は統括が受け、作ったものは必ずチェックを通してから出します。

## Codex など、プラグインを使わない場合
`templates/` の中身（`AGENTS.md`、案件・単価マスター・手順書・振り返りのフォルダ）をそのまま作業フォルダに置けば、記録の仕組みは同じように使えます。役割の指示は、`AGENTS.md` から読み込める場所に別ファイルとして置いてください。

## 注意
- 記録を書くのはAI任せです。書き忘れたら「ログを書いて」（`/log`）と言ってください
- お客様の個人情報は、作業フォルダの外に出さない前提です
- 見積書・返信文の送信は、人が確認してから行ってください
