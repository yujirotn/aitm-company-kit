# 採用した役割

`_役割テンプレート.md` は記入用のひな型です。聞き取りで採用した役割ごとに、`<役割ID>.md` を新規作成してください。役割IDは重複しない英数字とハイフンを使います。初期案が合う場合も、この作業先に必要な内容を具体化して保存します。プラグインの `agents/` や元リポジトリの存在を前提にしません。

各役割の名前、担当範囲、入力、成果物、停止・人への確認条件、引き渡し先を本人と確認します。未確認欄がある役割は導入状態に残し、その業務を確定処理に使いません。`会社設定.md` の採用役割表と `AGENTS.md` の役割参照を、このローカルファイルへ結びます。共通の作業手順は `手順書/` に置き、この役割 MD から `../手順書/<手順名>.md` のように、その MD の場所を起点とする相対パスで参照します。参照先がなければ実行前に止まって確認します。

Claude Code でこの役割をサブエージェントとして使う場合は、作業先の `.claude/agents/<役割ID>.md` に YAML frontmatter の `name` と `description` を持つファイルを作り、本文で `役割/<役割ID>.md` と関連する `手順書/` を最初に読むよう指示します。作業先にある役割 MD を正本にします。再設定で役割を外す場合は、本人の確認のうえ `.claude/agents/` から外して保管し、旧 MD を削除しません。Codex は `AGENTS.md` のリンクから直接この役割 MD を読みます。
