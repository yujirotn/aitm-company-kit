---
description: 顧客と案件を確定し、決定・未決・担当・次アクションを分けて議事録を追加
argument-hint: <顧客ID> <案件ID>
---

以下の `顧客/<顧客ID>/案件/<案件ID>/` は標準例。`会社設定.md` に承認済みの別保存先と一覧・台帳の対応表があればそれを使う。対応が曖昧なら書かずに確認する。

引数: $ARGUMENTS。`顧客/顧客一覧.md`、その顧客の案件一覧、対象案件 README を照合する。曖昧なら書かずに聞く。

1. 日時、参加者、議題、発言と資料、決定の根拠、未決事項、各アクションの担当と期限を確認する。不明な欄は未確認と書く。発言の原文と AI の要約を区別する。
2. `顧客/<顧客ID>/案件/<案件ID>/議事録/` に `${CLAUDE_PLUGIN_ROOT}/templates/顧客/_テンプレート/案件/_テンプレート/議事録/_議事録テンプレート.md` を基に `YYYY-MM-DD_連番.md` を新規作成する。同名なら上書きせず次の連番を選び、人に示す。
3. その案件の README の決定・未解決と経過ログに議事録の相対パスを追記する。別顧客や別案件には書かない。外部共有は人の確認後。
