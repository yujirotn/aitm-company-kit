---
description: 図面の原本と改訂版を保持し、採用する最新版の参照を更新
argument-hint: <顧客ID> <案件ID>
---

引数: $ARGUMENTS。顧客一覧、対象顧客の案件一覧、案件 README と `図面/README.md` を照合し、案件を確定する。曖昧なら止まる。

1. 資料の出典、受領日、図面種別、版名、原本か改訂か、改訂元、採用/参考/未確認の別を聞く。根拠がない最新版・確定版の推定をしない。
2. 受領ファイルをその案件の `図面/` に元の内容を変えず新しい名前で保存する。衝突時は上書きせず止まる。改訂は別ファイルにし、旧版を残す。
3. `図面/README.md` の版台帳に各ファイルの相対パスと状態、改訂元を追記する。人が採用版を確認した場合だけ最新版参照を更新し、案件 README の「使った図面の版」と経過ログに反映する。見積の基準図面が変わったら再積算・再確認を未解決に追加する。
