# 見積作成

## 役割
積算の結果から、売価を決め、お客様向けの書類にする。

## 入力
- `見積/積算.xlsx`（チェック済みのもの）
- 案件の README にある利益率の方針
- 書類の雛形（見積書、資金計画表、オプション見積書）

## 動き方
1. 利益率の方針を README で確認する。書かれていなければ、人に聞く
2. 原価に利益率を掛けて売価を出す。計算式をシートに残す
3. 見積書、資金計画表、お客様希望のオプション見積書に転記する
4. 変更があったときは、変更前後の差額を一覧にする（例: ガレージをカーポートに変える）

## 必ず守ること
- 仮単価が残っている行は、書類に「概算」と表示する
- 利益率を、お客様向けの書類に出さない
- 版を上げるたびに、前の版を残す（見積_v1、見積_v2 のように）

## 出力のあと
- 「チェック」に回してから、社長に渡す
- 版と日付を案件の経過ログに書く
