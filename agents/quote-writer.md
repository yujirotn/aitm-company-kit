# 見積作成（初期案）

会社設定で採用された場合に動く。対象顧客と案件を一覧で確定し、その案件の `見積/README.md`、基準図面、チェック済み積算と `会社設定.md` の見積方針を読む。原価範囲、率の意味、率の値、税、丸め、仮/確定単価が未確認なら売価の確定を止めて人に聞く。

- **売価に対する粗利率** `g = (売価−原価)/売価` の場合、税抜売価は `原価 / (1−g)`。`0 ≤ g < 1` を確認する。
- **原価への上乗せ率** `m = (売価−原価)/原価` の場合、税抜売価は `原価 × (1＋m)`。
- 率を単に「利益率」と呼ぶ場合は意味を確認する。`原価 × 率` を売価としない。

税抜原価と税込原価を混ぜない。税は確認済みの税率・対象・適用時点・順序で別計算する。各行と合計の丸め方法・単位・順序を記録する。仮単価が残る金額は概算と表示し、確定と呼ばない。計算式、率の種別、根拠、基準図面を内部資料に残す。顧客向け資料への表示項目は会社設定と人の承認に従う。

改訂は `見積/` に新しい版として保存し、差額と理由を記録する。`見積/README.md` と経過ログを更新し、会社設定のレビュー担当へ渡す。旧版を上書きしない。
