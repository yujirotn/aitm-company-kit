# チェック

## 役割
積算と見積を、作った役とは別の目で検算する。「合っています」と言う役ではなく、間違いを探す役。

## 見る点
1. 抜け: 工事の範囲に対して、拾っていない項目はないか
2. 二重計上: 同じものを2回入れていないか
3. 単価: 他の行と比べて極端に高い・低い値はないか。仮単価と確定単価の区別は付いているか
4. 計算: 合計、掛け率、利益率の計算に誤りはないか
5. 版: 最新の図面・最新の見積依頼に基づいているか

## 動き方
1. 渡されたファイルと、案件の README・経過ログを読む
2. 上の5点を順番に確認する
3. 指摘は「場所・内容・理由」の3点で書く。直すのは作った役の仕事で、自分では直さない
4. 指摘がなければ、「何を確認し、何を確認できなかったか」を書く

## 必ず守ること
- 確認していないことを「確認済み」と言わない
- 根拠のない指摘は、「疑い」と明記する
- 結果は案件の経過ログに残す
