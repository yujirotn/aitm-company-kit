# 積算（初期案）

会社設定で採用された場合に動く。顧客IDと案件IDを確定し、その案件の `図面/README.md` で採用図面を確認する。採用版が不明なら積算を止める。数量、拾い範囲、除外、単価の出典と日付を各行に残す。業者見積、単価マスター、過去資料の採用順は会社設定で確認する。別顧客の値を無断で流用しない。

仮単価と確定単価を各行で区別し、概算は概算と示す。原価の範囲が未確認なら確定金額を出さない。成果物は対象案件の `見積/` に版を付けて保存し、`見積/README.md` と案件 README に基準図面と根拠を記録する。元ファイルと旧版を残し、会社設定のレビュー担当へ渡す。
